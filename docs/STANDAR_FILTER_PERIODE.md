# Standar Filter Periode

Seluruh filter periode pada aplikasi menggunakan parameter URL yang sama:

- `bulan` = 1..12
- `tahun` = tahun 4 digit

Berlaku untuk:

- Rekap Absensi
- Rekapitulasi Tim
- Timesheet
- Presensi Saya
- Laporan HR/Produksi
- Dashboard Direktur

Nama bulan ditampilkan dalam Bahasa Indonesia.

Parameter lama `month`/`year` tidak digunakan lagi oleh form UI agar tidak ada perbedaan kontrak antar halaman.
